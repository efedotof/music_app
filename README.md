# 🎶 MusicApp

**MusicApp** is a modern cross-platform music application built with Flutter. It supports online search, local storage, favorites, and an integrated audio player with notification controls.

---

## 📱 Features

- 🔍 **Track Search**
  - Search music using the [Zaycev.net](https://zaycev.net) API
  - Supports searching by track name, artist, or album
  - Fetches cover art and metadata

- 🎧 **Built-in Audio Player**
  - Play/pause, skip to next/previous track
  - Playback controls via system notifications
  - Background playback support

- 💾 **Music Download**
  - Save tracks to local storage
  - Offline playback support
  - Automatic file organization

- ⭐ **Favorites**
  - Add tracks to favorites
  - Quick access to favorite music

- 📂 **Playlists**
  - Listen to ready-made playlists

---

## 🧑‍💻 Technologies

- **Flutter** — cross-platform development
- **Dio** — HTTP requests
- **just_audio** & **audio_service** — background-capable audio playback
- **Hive** — local storage
- **path_provider** — access to device file system
